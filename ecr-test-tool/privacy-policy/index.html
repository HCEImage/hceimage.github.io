ECR Test Tool

Privacy Policy

Effective date: September 13, 2026

HCEImage is developing ECR Test Tool as a utility for electronic cash register and payment terminal integration testing. This policy describes the current development application.

Current application scope

The application provides nexo Retailer V5 (MUG 8.0 / CASP V05) and V4 (MUG 4.1-LW / CASP V01) profiles over TCP on Android and desktop. A user can connect directly to a configured payment-terminal endpoint or enable the built-in Local POI simulator. The current automatic simulator generates, parses and validates the supported Sale request-and-response subset. Persistent transaction history, protocol traces and diagnostic report exports are not implemented.

Data collection and sharing

ECR Test Tool does not automatically collect or send personal data to HCEImage or third-party services. The application has no account, advertising, analytics, crash reporting or tracking.

Network access

The application opens a TCP connection only after the user selects Connect. For an external payment terminal, it connects to the IPv4 address and port entered by the user. The built-in simulator uses the device loopback interface and an automatically assigned local port. HCEImage does not operate a server for these exchanges and does not receive their contents.

Local data

Application preferences such as appearance, diagnostic level and whether the built-in simulator is enabled are stored locally on the device. Active connections, transaction configuration, generated XML and results are held only for the current application session and are not added to persistent history. Application backup is disabled. Android removes application data when the user clears it or uninstalls the application.

Diagnostic data

Complete request and response messages can contain sensitive test data. The application is intended for synthetic data and authorized test terminals in controlled development environments. Persistent diagnostic logs and report exports are not implemented in the current version.

Future features

This policy will be reviewed before adding persistent histories, protocol traces, diagnostic report exports, user-initiated sharing or any remote service.

Children's privacy

ECR Test Tool is a specialized developer utility and is not directed to children.

Policy website hosting

This public policy page is hosted by GitHub Pages. GitHub logs visitor IP addresses for security purposes under the GitHub Privacy Statement. This website hosting is separate from the application data practices described above.

Changes to this policy

This policy may be updated when the application's functionality or data practices change. The effective date above identifies the current version.

Contact

For privacy or support questions, contact HCEImage at hceimage@gmail.com. If you email us, we receive your email address, message and any attachments you choose to send and use them to respond to your request. Do not include real payment card data or other sensitive information in support messages.
