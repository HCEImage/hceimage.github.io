ECR Test Tool

Privacy Policy

Effective date: September 10, 2026

HCEImage is developing ECR Test Tool as a utility for electronic cash register and payment terminal integration testing. This policy describes the current 0.1.0 development application.

Current application scope

The current application presents an initial ECR-B over TCP profile and shared Android and desktop user interface. Live protocol communication, transaction execution, persistent traces and diagnostic report exports are not implemented.

Data collection and sharing

ECR Test Tool does not automatically collect or send personal data to HCEImage or third-party services. The application has no account, advertising, analytics, crash reporting or tracking.

Network access

The Android application declares network access for the planned direct connection to payment terminals. The current development build does not open a network connection. Future versions will update this policy before they exchange terminal messages or retain connection settings.

Local data

The current development build does not persist transaction data, connection profiles, protocol traces or reports. Application backup is disabled. Android removes application data when the user clears it or uninstalls the application.

Future features

This policy will be reviewed before adding live protocol communication, persistent histories, diagnostics, report exports or user-initiated sharing.

Children's privacy

ECR Test Tool is a specialized developer utility and is not directed to children.

Policy website hosting

This public policy page is hosted by GitHub Pages. GitHub logs visitor IP addresses for security purposes under the GitHub Privacy Statement. This website hosting is separate from the application data practices described above.

Changes to this policy

This policy may be updated when the application's functionality or data practices change. The effective date above identifies the current version.

Contact

For privacy or support questions, contact HCEImage at hceimage@gmail.com. If you email us, we receive your email address, message and any attachments you choose to send and use them to respond to your request. Do not include real payment card data or other sensitive information in support messages.
