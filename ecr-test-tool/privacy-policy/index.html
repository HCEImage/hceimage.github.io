ECR Test Tool

Privacy Policy

Effective date: September 26, 2026

HCEImage is developing ECR Test Tool as a utility for electronic cash register and payment terminal integration testing. This policy describes the current development application.

Current application scope

The Android and desktop applications support nexo Retailer profiles over TCP. A user can connect to a configured payment-terminal endpoint or enable the built-in Local POI simulator. Supported operations and session controls exchange, parse and validate protocol messages. Connection runs, protocol exchanges and diagnostic results can be reviewed in local history and exported as reports.

Data collection and sharing

ECR Test Tool does not automatically collect or send personal data to HCEImage or third-party services. The application has no account, advertising, analytics, crash reporting or tracking.

Network access

The application opens a TCP connection only after the user selects Connect. For an external payment terminal, it connects to the IPv4 address and port entered by the user. The built-in simulator uses the device loopback interface and an automatically assigned local port. HCEImage does not operate a server for these exchanges and does not receive their contents.

Local data

Application preferences, connection configuration and history are stored locally. History can include endpoint details, protocol-session and operation results, validation findings, raw request and response XML, timing and optional notes. The newest 100 connection runs are retained by default; users can delete saved runs or clear history. Active runs remain visible until they end. Android application backup is disabled. Clearing application data or uninstalling removes its local history, but not files previously exported to another destination.

Diagnostic data

Complete request and response messages can contain sensitive test data. The application is intended for synthetic data and authorized test terminals in controlled development environments. The user can export summary or detailed diagnostic reports in Markdown, HTML or PDF; detailed reports can include raw XML and notes. Exported files leave the application only through an explicit user action and are handled by the selected destination. HCEImage does not receive these reports automatically.

Future features

This policy will be reviewed before adding any remote service or changing what the application stores or shares.

Children's privacy

ECR Test Tool is a specialized developer utility and is not directed to children.

Policy website hosting

This public policy page is hosted by GitHub Pages. GitHub logs visitor IP addresses for security purposes under the GitHub Privacy Statement. This website hosting is separate from the application data practices described above.

Changes to this policy

This policy may be updated when the application's functionality or data practices change. The effective date above identifies when this policy took effect.

Contact

For privacy or support questions, contact HCEImage at hceimage@gmail.com. If you email us, we receive your email address, message and any attachments you choose to send and use them to respond to your request. Do not include real payment card data or other sensitive information in support messages.
