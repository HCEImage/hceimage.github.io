EMV Card Analyzer

Privacy Policy

Effective date: September 7, 2026

HCEImage is developing EMV Card Analyzer as a utility for EMV payment card inspection and diagnostics. This policy describes the current application foundation.

Current application scope

This policy describes the initial 0.1.0 application. It displays application information and local NFC availability and can open Android NFC settings. Card reading, APDU exchange, saved analysis history, diagnostic reports and USB readers are not implemented in this version.

Data collection and sharing

EMV Card Analyzer does not automatically collect or send personal data to HCEImage or third-party services. The application has no account, advertising, analytics, crash reporting, tracking or network services. Support messages sent by the user are described below.

Device information and local state

The application checks whether the device has an NFC adapter and whether NFC is enabled. This status is used locally to display device readiness. The current version does not read payment card data or create persistent card-analysis history. Screen state is held locally while the application is in use; Android may retain temporary state to restore its interface. Application backup is disabled.

NFC permission

The application declares the Android NFC permission and uses local adapter status. It does not activate NFC reader mode or exchange commands with cards in this version. Opening NFC settings is an explicit user action.

Future features

Card reading and analysis are planned. This policy will be reviewed and updated before releasing features that access, store, export or otherwise handle card data. The current statements do not describe those future features as available.

Children's privacy

EMV Card Analyzer is a specialized developer utility and is not directed to children.

Policy website hosting

This public policy page is hosted by GitHub Pages. GitHub logs visitor IP addresses for security purposes under the GitHub Privacy Statement. This website hosting is separate from the application data practices described above.

Changes to this policy

This policy may be updated when the application's functionality or data practices change. The effective date above identifies the current version.

Contact

For privacy or support questions, contact HCEImage at hceimage@gmail.com. If you email us, we receive your email address, message and any attachments you choose to send, and use them to respond to your request. Do not include real payment card data or other sensitive information in support messages.
