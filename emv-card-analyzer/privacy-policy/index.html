EMV Card Analyzer

Privacy Policy

Effective date: October 1, 2026

HCEImage provides EMV Card Analyzer as a development and testing utility for inspecting contactless payment cards in authorized diagnostic environments.

Data collection and sharing

EMV Card Analyzer processes card data and diagnostics on the device. It does not automatically send personal data, analyses or diagnostics to HCEImage or third-party services. The application does not include accounts, advertising, analytics, crash reporting, tracking or other network services. User-initiated copying, exports and support contact are described below.

Data stored on the device

The application automatically saves finished card-read results in application-private storage. Depending on the card, a saved analysis can contain raw APDUs, decoded card data, timestamps, diagnostic findings and an optional user note. Imported traces are previewed locally. Choose Save to history to store a copy. Saved imports follow the same retention and deletion rules as local reads.

History retains the newest 100 analyses by default. You can select 500, 1,000 or Unlimited, delete an individual record or clear all history. A finite limit removes the oldest excess records. Clearing history does not remove separately exported files, original import files, clipboard copies or system diagnostic logs.

Preferences and acknowledgement of the development-use notice are stored locally. Clearing app data or uninstalling removes app-private data. The app excludes its data from Android cloud backup and device-to-device transfer.

Captured card data

Captured data can include a card number, expiry date, cardholder information and other sensitive values. Summary initially masks the card number except for the last four digits. You can reveal it there. The mask affects only Summary. APDU and tag details, Full evidence exports and detailed diagnostic logs can still contain the captured values.

Copying and diagnostic logs

You can explicitly copy raw APDUs and decoded values to the system clipboard. Android receives a sensitive-content flag to suppress previews on supported devices. The operating system controls clipboard access and retention.

Logcat detail controls local Android logs. Errors records failures. Sessions adds reader and result events without complete APDU payloads. APDUs includes raw commands and responses that may contain sensitive data. The Google Play app defaults to Sessions. Debug builds default to APDUs. You can choose a lower detail level in Settings. Android manages these logs separately from History. Device debugging tools and user-created diagnostic captures can include them.

Exporting and sharing diagnostics

You can explicitly save or share a Markdown, HTML or PDF report, or a portable analysis trace. Full evidence reports and traces can include raw APDUs, decoded values and saved notes. A Redacted report omits card-derived values and notes while retaining diagnostic context, such as timestamps, status words and timing. Review the file and remaining context before sharing.

Save uses Android's document picker. Share writes the export to the app's cache and opens the Android Sharesheet. The selected application receives temporary read access to the cached file and handles its copy under its own privacy practices. HCEImage receives a file only if you choose to send it to us.

NFC and contactless card reading

The app checks whether the device has NFC and whether it is enabled. It uses built-in Android NFC to exchange diagnostic commands and responses with a nearby card after you choose Start analysis. Reader mode stops when you choose Stop analysis, leave Analyzer or put the app in the background. By default it also stops when a result is ready. You can open Android NFC settings explicitly. The app does not perform payments or change the default payment service.

Children's privacy

EMV Card Analyzer is a specialized developer utility and is not directed to children.

Website hosting

This public policy page and the developer guide linked from in-app guidance are hosted by GitHub Pages. Opening the guide is an explicit user action in an external browser. GitHub logs visitor IP addresses for security purposes under the GitHub Privacy Statement. This website hosting is separate from the application data practices described above.

Changes to this policy

This policy may be updated when the application's functionality or data practices change. The effective date above identifies when this policy took effect.

Contact

For privacy or support questions, contact HCEImage at hceimage@gmail.com. If you email us, we receive your email address, message and any attachments you choose to send, and use them to respond to your request. Do not include real payment card data or other sensitive information in support messages.
