EMV Card Analyzer

Privacy Policy

Effective date: September 8, 2026

HCEImage is developing EMV Card Analyzer as a utility for EMV payment card inspection and diagnostics. This policy describes local card analysis and diagnostic processing.

Current application scope

This policy describes the 0.1.0 development application. It reads supported contactless payment applications over NFC and displays APDU exchanges and decoded data. Persistent analysis history, diagnostic report export and USB readers are not implemented.

Data collection and sharing

EMV Card Analyzer does not automatically collect or send personal data to HCEImage or third-party services. The application has no account, advertising, analytics, crash reporting, tracking or network services. Support messages sent by the user are described below.

Device information and local state

The application checks whether the device has an NFC adapter and whether NFC is enabled. Card application data and raw APDU exchanges are processed locally and retained in memory for the current analysis, until a new analysis starts, the user leaves Analyzer or the foreground, or the Activity is recreated. Depending on the card, these data may include account numbers, expiry dates, cardholder information or other sensitive values. The application does not automatically save card-analysis history. It stores the selected theme, diagnostic detail preference and acknowledged development-use notice version locally. Settings survive restarts and are removed when app data is cleared or the app is uninstalled. Application backup is disabled.

Local diagnostics

The diagnostic preference controls Android Logcat output. Errors logs failures; Sessions adds session events; APDUs also logs raw commands and responses, which may contain sensitive card data. APDUs is the default. Android manages these logs separately from the current analysis; clearing the screen does not clear system logs. Users can choose a lower detail level in Settings. Copying displayed data or sharing device logs is a user-controlled action, not an automatic upload by the application.

NFC permission

The Android NFC permission is used to read cards after the user selects Start analysis. Reader mode is released on Stop, leaving the Analyzer screen, Activity pause and completion or failure. Opening NFC settings is an explicit user action. The app does not perform payments or change the default payment service.

Future features

This policy will be reviewed before adding persistent card-analysis history, diagnostic report export or other changes to card-data handling.

Children's privacy

EMV Card Analyzer is a specialized developer utility and is not directed to children.

Policy website hosting

This public policy page is hosted by GitHub Pages. GitHub logs visitor IP addresses for security purposes under the GitHub Privacy Statement. This website hosting is separate from the application data practices described above.

Changes to this policy

This policy may be updated when the application's functionality or data practices change. The effective date above identifies the current version.

Contact

For privacy or support questions, contact HCEImage at hceimage@gmail.com. If you email us, we receive your email address, message and any attachments you choose to send, and use them to respond to your request. Do not include real payment card data or other sensitive information in support messages.
