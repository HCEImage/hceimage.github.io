EMV Card Analyzer

Inspect supported contactless card applications

Android · Open testing

Run a bounded EMV analysis over Android NFC, follow the APDU exchange and preserve diagnostic results locally.

Before starting

  • Use an Android device with NFC enabled.
  • Analyze only cards and test media that you are authorized to inspect.
  • Keep other NFC cards and tags away, and hold the card steadily within the phone's NFC field during analysis.

EMV Card Analyzer is a bounded diagnostic reader, not a payment kernel. It does not authorize transactions, validate issuer cryptography or determine whether a card is genuine.

Run an analysis

  1. Open the Analyzer and confirm that NFC is available and enabled.
  2. Start an analysis, then hold the contactless card against the device's NFC antenna.
  3. Keep the card in place while the application performs bounded directory selection, application selection, processing-options retrieval and supported AFL record reading.
  4. Wait for a completed, partial, interrupted or failed result before removing the card.

Understand the result

A completed result means that the supported analysis procedure reached its normal boundary. Partial results preserve useful data when one or more applications could not be read completely. Interrupted results identify loss of communication, while failed results provide the available diagnostic reason.

Compatibility varies between cards, devices and application profiles. An incomplete analysis does not by itself establish that a card is invalid.

Inspect APDU and EMV data

Application details organize discovered records and tags. The APDU timeline exposes raw commands and responses with contextual command, status-word and BER-TLV decoding where their meaning is known. Bundled offline references help interpret recognized values without sending analysis data to a network service.

Use history and reports

Analysis snapshots and optional notes are stored locally on the device. History supports later review, deletion and diagnostic report export through Android system interfaces. Choose a summary or detailed report according to how much APDU and decoded context the recipient needs.
