HCE Test Tool

Privacy Policy

Effective date: September 3, 2026

HCEImage provides HCE Test Tool as a development and testing utility for controlled contactless payment integration environments.

Data collection and sharing

HCE Test Tool does not collect, transmit, sell, or share personal data with HCEImage or third parties. The application does not include advertising, analytics, crash reporting, tracking, or other network services.

Data stored on the device

The application stores test-session history, settings, APDU exchanges, validation results, and optional notes locally on the user's device. Bundled card profiles contain synthetic test data only. This information is used solely to provide the application's testing and diagnostic features.

Users can delete individual history records or clear all stored history from within the application. Uninstalling the application removes its locally stored application data, subject to the device operating system's backup and restore behavior.

Exporting and sharing reports

Users may explicitly save or share diagnostic reports in Markdown, HTML, or PDF format. Export and sharing occur only after a user action and use the destination or application selected by the user. HCEImage does not receive these reports.

NFC and contactless card emulation

HCE Test Tool uses Android NFC host card emulation to exchange test APDU commands and responses with a nearby compatible reader. This processing occurs locally between the Android device and the reader.

The application is intended only for authorized development, integration testing, and controlled test environments. It must not be used with production payment data or for real payment transactions.

Children's privacy

HCE Test Tool is a specialized developer utility and is not directed to children.

Policy website hosting

This public policy page is hosted by GitHub Pages. GitHub may process standard technical information, such as IP addresses, for security and service operation under the GitHub Privacy Statement. This does not change HCE Test Tool's application data practices described above.

Changes to this policy

This policy may be updated when the application's functionality or data practices change. The effective date above identifies the current version.

Contact

For privacy or support questions, contact HCEImage at hceimage@gmail.com.
