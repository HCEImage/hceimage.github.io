Purpose-built testing tools

Built for developers and integration engineers working with cards, terminals and electronic cash registers in controlled test environments.

HCE Test Tool

Android · Open testing

An Android developer tool for emulating synthetic EMV contactless card profiles, applying optional in-memory test-security overrides, inspecting and decoding APDU exchanges, validating test flows, and keeping local history with notes and exportable diagnostic reports.

Join the Android test Privacy policy

EMV Card Analyzer

Android · Open testing

An Android developer tool for inspecting supported EMV card applications, contextually decoding APDU and BER-TLV data, browsing application records and captured tags, and keeping local analysis history with notes and exportable diagnostic reports. Clear result states and bundled offline references support controlled diagnostics; the bounded analyzer is not a payment kernel.

ECR Test Tool

In development

A multiplatform developer tool for simulating an electronic cash register, testing payment terminal integrations and inspecting protocol exchanges. The current development build supports nexo Retailer V5 and V4 profiles over TCP, with an optional Local POI simulator and a parsed Sale request-and-response preview.
