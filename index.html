HCE Test Tool

Android

Emulate Built-in, Imported or Created synthetic Visa, Mastercard, American Express and JCB profiles. Import a definition or copy an existing profile, configure temporary test security overrides and reset them to profile defaults. Use optional simulated device verification on supported mobile EMV profiles, inspect APDU exchanges and keep local history with notes and exportable diagnostic reports.

EMV Card Analyzer

Android

An Android developer tool for inspecting supported EMV card applications, contextually decoding APDU and BER-TLV data, browsing application records and captured tags, and keeping local analysis history with notes, exportable diagnostic reports and portable traces. Clear result states and bundled offline references support controlled diagnostics; the bounded analyzer is not a payment kernel.
